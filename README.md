# Rota do Código

Jogo educativo **WEB** do projeto Desafio Arcade, aprovado em 07/10/2026. O jogador monta comandos para um robô, acompanha a execução e corrige a trajetória.

Repositório: https://github.com/luccalck/desafio-arcade

Este commit identifica o repositório vazio e estabelece a base para pull requests. Não contém jogo, CI ou publicação. Não é evidência de revisão por outro integrante e não conta entre os dez PRs exigidos.

As próximas mudanças seguem branches `feature/*`, Conventional Commits e PR com revisão humana de outro integrante e CI obrigatório. O jogo será um site estático responsivo, com build offline e esteira em GitHub Actions/Pages.

Conceito e criação preparados com assistência do Codex. O registro detalhado de IA acompanhará o primeiro PR. Identificação do squad e dos quatro integrantes será fornecida posteriormente pelo responsável; não há dados fictícios neste repositório.

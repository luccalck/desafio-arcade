# Histórico preservado

Esta pasta guarda planos, especificações e evidências de versões anteriores. Os arquivos ajudam a rastrear decisões e execuções; não são o roteiro vigente.

- `planos/`: planos anteriores, preservados com seus nomes/datas.
- `especificacoes/`: concepções anteriores e evolução aprovada.
- `evidencias/`: resultados anteriores, com limites e versão de origem.

Para continuar o trabalho, use o [índice atual de execução](../execucao/00-indice-geral.md). O [checklist atual](../gestao/checklist-avaliacao.md) é a fonte do estado dos requisitos. Evidências atuais ficam em `docs/evidencias/`; GDD e relatório ficam diretamente em `docs/`.
